# SmartShop free-only project rule

SmartShop uses only free and open-source dependencies and free service tiers. Contributors must never automatically upgrade a plan, add billing details, enable paid GitHub runners, enable paid Supabase add-ons, purchase a domain, or publish through Google Play during this stage.

Builds use standard GitHub-hosted runners for this public repository and Supabase's Free Plan only. The test APK is distributed directly as a GitHub Actions artifact. If a requirement cannot be completed without cost, stop that part and record the limitation; do not activate a trial or create a charge.
